# RelCurv-Bilevel-HSG

**Relation-Level Curvature Guided Bilevel Semantic Alignment for Free-Grained
Hierarchical Recognition**

This repository extends the Free-Grained Hierarchical Visual Recognition code
base with a semantic closed loop designed for both part-dominated categories
(CUB-200) and configuration-dominated categories (FGVC-Aircraft).

The method does not directly optimize a weighted alignment error. Instead, a
curvature-aware policy chooses which semantic parts or part relations guide a
virtual support-view update. A query-view loss then evaluates whether that
update improved alignment and updates the policy through a differentiable
hypergradient.

## What is new

- Multiple visual semantic tokens shared by training and inference; captions
  are training-only teachers.
- Local semantic-part branch retained for CUB.
- Pairwise relation branch for Aircraft: 8 parts produce 28 undirected
  appearance-layout relations.
- Relation-level HVP curvature computed in FP32 on stopped feature/parameter
  copies.
- Explicit one-step bilevel objective with `create_graph=True`.
- Policy parameters live only in a separate meta optimizer.
- All policy weights used by real task losses are detached.
- Independent zero-initialized local and relation residual gates.
- Support/query views generated by independent augmentations.

## Optimization

For relation error `e_ab`, policy `p_phi`, lower-level adapter `psi`, and fixed
outer distribution `q`:

```text
psi+ = psi - eta * grad_psi sum_(a,b) p_phi(a,b) e_ab(support; psi)
L_meta(phi) = sum_(a,b) q(a,b) e_ab(query; psi+)
```

The recommended outer distribution is uniform. Relation HVP is used as a
stopped structural prior for the policy, avoiding a self-confirming objective
where curvature both selects and judges the same relations.

This is an explicit bilevel objective optimized by one-step differentiable
unrolling. It does not claim that the inner argmin is solved exactly.

## Installation

Recommended environment:

- Python 3.10
- PyTorch 2.1.2
- torchvision 0.16.2
- CUDA 12.1

```bash
conda create -n relcurv python=3.10
conda activate relcurv
pip install -r requirements.txt
pip install torch==2.1.2 torchvision==0.16.2 \
  --index-url https://download.pytorch.org/whl/cu121

export PYTHONPATH=deit/:deit/dataset/:$PYTHONPATH
```

Download the ImageNet-pretrained DeiT-small checkpoint:

```text
https://dl.fbaipublicfiles.com/deit/deit_small_patch16_224-cd65a155.pth
```

## Data

- Aircraft: `--data-path` is the directory containing
  `fgvc-aircraft-2013b/`.
- CUB: `--data-path` points to `CUB_200_2011/images_split` containing `train/`
  and `test/`.
- Included caption files: `captions/air_caps.txt` and
  `captions/cub_caps.txt`.

## Train Aircraft with the full V6 method

```bash
python deit/main_hier_partial.py \
  --model deit_small_patch16_224 \
  --batch-size 32 \
  --epochs 100 \
  --num_workers 8 \
  --data-set AIR-HIER \
  --data-path /data \
  --output_dir ./output/air_relcurv_v6 \
  --texts captions/air_caps.txt \
  --sim_loss_weight 1 \
  --sp_proportion 0.3 \
  --fm_proportion 0.6 \
  --seed 0 \
  --random_seed 0 \
  --finetune deit_small_patch16_224-cd65a155.pth \
  --enable-bilevel \
  --meta-scope relation \
  --num-parts 8 \
  --lam-cls 0.0 \
  --lam-attr 1.0 \
  --proto-align-weight 0.0 \
  --meta-start-epoch 5 \
  --meta-inner-lr 0.1 \
  --meta-lr 1e-4 \
  --meta-real-weight 0.1 \
  --meta-reference-mix 0.5 \
  --relation-hvp-samples 1 \
  --meta-q uniform
```

Start with batch size 32 because two views and HVP increase memory use. Reduce
`--meta-adapter-rank` and `--semantic-rank` to 32 if needed.

## Train CUB safely

Start with the local part loop, which matches CUB's local discriminative cues:

```bash
python deit/main_hier_partial.py \
  --model deit_small_patch16_224 \
  --batch-size 32 \
  --epochs 100 \
  --num_workers 8 \
  --data-set BIRD-HIER \
  --data-path /data/CUB_200_2011/images_split \
  --output_dir ./output/cub_part_bilevel_v6 \
  --texts captions/cub_caps.txt \
  --sim_loss_weight 1 \
  --sp_proportion 0.1 \
  --fm_proportion 0.5 \
  --seed 0 \
  --random_seed 0 \
  --finetune deit_small_patch16_224-cd65a155.pth \
  --enable-bilevel \
  --meta-scope part \
  --num-parts 8 \
  --meta-start-epoch 5 \
  --meta-q uniform
```

Use `--meta-scope hybrid` only as a reported ablation after confirming the
relation gate does not reduce CUB validation FPA.

## Verify implementation invariants

```bash
python -m compileall -q deit
PYTHONPATH=deit python -m unittest -v deit/test_semantic_bilevel.py
```

The tests cover relation HVP validity, nonzero policy hypergradients, isolation
of policies from ordinary losses, probability floors, and flip-invariant
relation geometry.

## Key files

- `deit/semantic_bilevel.py`: relation construction, HVP, policies, adapters,
  and one-step unrolled objectives.
- `deit/semantic_part_v4.py`: curvature-aware semantic part generation.
- `deit/models_hier.py`: visual/text semantic bridge and safe residual fusion.
- `deit/engine_vit_hier_partial.py`: separated meta/model optimization.
- `BILEVEL_SEMANTIC_LOOP.md`: equations, design boundaries, and ablation matrix.

## Evaluation protocol

Run at least three seeds on both Aircraft and CUB. Select checkpoints using a
held-out validation split and the declared primary metric (FPA); do not select
epochs on the test set. Report Species/Variant, Family, Order/Manufacturer, FPA,
TICE, policy entropy, effective relation count, and both learned residual gates.
